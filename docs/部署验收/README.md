# 部署验收目录

这个目录里的文档分成两类：

- 当前仍有效的部署 / 运行 / 对接 / 验收文档
- 特定板端环境、专项问题或某次评估留下的条件性文档

如果只是为了接手当前项目，不要从专项文档开始读，先看当前有效文档。

## 文件说明

- `环境目录说明.md`
  - `packages/`、`venv-gst/`、四个脚本、`systemd` 模板的用途
- `运行路径说明.md`
  - 运行期会读写哪些目录、模型、日志、截图和控制文件
- `甲方设备MPP环境说明.md`
  - 特定甲方板端的专项说明
  - 说明某轮排查里为什么该设备无法命中当前 `FFmpeg` 优先硬解，且也缺少备用 `GStreamer+mpp` 链路
- `部署前性能评估与低风险优化建议.md`
  - 带时间基准的性能评估文档
  - 重点是某轮双路压测与低风险优化建议
- `心跳与截图对接说明.md`
  - 给甲方/联调方的心跳判活与手动截图对接文档
  - 说明 `device_id` 命名空间、`launch_id` 判活、多路 `key` 调用方式和截图命令机制
- `板端验收清单.md`
  - 从安装环境到启动 Web、启动推理、检查多路隔离、心跳与截图的完整验收步骤
- `甲方RK3588板端Rockchip MPP环境差异与驱动补齐说明.md`
  - 面向板商 / BSP 供应方的专项差异说明
- `甲方RK3588板端多媒体环境资源提供清单（厂商执行版）.md`
  - 面向厂商的资源交付清单

## 建议使用方式

- 当前有效文档的优先顺序：
  1. `环境目录说明.md`
  2. `运行路径说明.md`
  3. `心跳与截图对接说明.md`
  4. `板端验收清单.md`
- 条件性文档的使用顺序：
  - 若甲方要推进硬解环境补齐，再看 `甲方设备MPP环境说明.md`
  - 若要发给板商/BSP，再看两份 `甲方RK3588板端*.md`
  - 若准备评估双路或压缩资源，再看 `部署前性能评估与低风险优化建议.md`

## 阅读提醒

- 本目录不是项目主链路设计文档，主链路仍以根目录 `README.md`、`cleaningcar/README.md` 和实际代码为准
- 看到“甲方设备”“某轮评估”“专项口径”这类表述时，要先确认该文档是不是你当前场景
