# 部署验收目录

这个目录只放板端部署和验收相关文档。

## 文件说明

- `环境目录说明.md`
  - `packages/`、`venv-gst/`、四个脚本、`systemd` 模板的用途
- `运行路径说明.md`
  - 运行期会读写哪些目录、模型、日志、截图和控制文件
- `甲方设备MPP环境说明.md`
  - 说明为什么甲方设备当前不能启用 `GStreamer+mpp`
  - 给出两条处理路线：换系统或由厂家编译 Focal 适配插件
- `部署前性能评估与低风险优化建议.md`
  - 说明双路推理当前是怎样实现的
  - 评估双路在软件解码口径下的资源开销
  - 给出本轮收益最快、风险最小的优化顺序
- `心跳与截图对接说明.md`
  - 给甲方/联调方的心跳判活与手动截图对接文档
  - 说明 HTTP 调用方式、命令文件机制和推荐相对路径写法
- `板端验收清单.md`
  - 从安装环境到启动 Web、启动推理、检查心跳与截图的完整验收步骤

## 建议使用方式

- 上板前先看 `环境目录说明.md`
- 若甲方要推进 MPP，先看 `甲方设备MPP环境说明.md`
- 若准备上双路，先看 `部署前性能评估与低风险优化建议.md`
- 需要排查路径问题时看 `运行路径说明.md`
- 需要给甲方联调时看 `心跳与截图对接说明.md`
- 正式验收按 `板端验收清单.md` 逐项执行
