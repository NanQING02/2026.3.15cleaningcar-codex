# 环境目录说明

## `packages/`

用途：

- 存放 RKNN 运行依赖
- 存放 `rknn_toolkit_lite` 的 wheel 包
- 存放 `librknnrt.so`
- 存放 RGA 相关库和头文件

`install_runtime_venv.sh` 会优先从这里安装或复制运行依赖。

## `venv-gst/`

用途：

- 项目的 Python 虚拟环境
- 一般包含 `fastapi`、`uvicorn`、`opencv`、项目依赖和 RKNN Python 包

说明：

- 如果该目录是从别的设备直接拷贝过来的，可能因 Python 路径或系统环境不同而失效
- 失效时直接执行：

```bash
FORCE_SETUP=1 ./install_runtime_venv.sh
```

## `install_runtime_venv.sh`

用途：

- 检查 `configs/config.json`
- 检查或重建 `venv-gst/`
- 安装系统依赖
- 从 `packages/` 安装 RKNN/RGA 文件
- 启动 `web.server`

## 推荐做法

- `packages/` 跟项目一起带到 RKNN 平台
- `venv-gst/` 可以一起带过去，但不要假定一定能直接用
- 配置文件里的检测后处理开关 `video.fp_output_mode` 也应跟配置一同带过去
