# RK3588 轻量开发迁移说明

本分支用于把当前项目迁移到另一台 RK3588 上继续开发，同时尽量缩小交付体积并保留 Git 能力。

## 这个轻量分支保留的内容

- 主程序代码：`cleaningcar/`、`web/`、`utils/`
- 启动与配置：`start_web_server.sh`、`install_runtime_venv.sh`、`run_zone_detect.py`、`configs/`
- RK3588 运行依赖：`packages/`、`models/`、`fonts/`
- 开发辅助：`tests/`、`docs/`
- 仍被测试引用的兼容模块：`future_modules/acceleration/` 以及少量旧链路占位代码

## 这个轻量分支刻意不带的内容

- IDE 元数据：`.idea/`
- 临时资料与板端试验目录：`tmp/`
- 历史大模型目录：`future_modules/legacy_models/`

这意味着：

- 当前分支更适合继续开发、提交、打包和同步到新板端。
- 如果需要查看原始完整历史或历史大模型，请切回原分支。

## 在当前机器导出 bundle

```powershell
git bundle create ..\\cleaningcar-rk3588-dev-min.bundle codex/rk3588-dev-min
```

生成的 `cleaningcar-rk3588-dev-min.bundle` 可以直接拷贝到另一台 RK3588。

## 在另一台 RK3588 上恢复为 Git 仓库

```bash
git clone -b codex/rk3588-dev-min /path/to/cleaningcar-rk3588-dev-min.bundle cleaningcar-codex
cd cleaningcar-codex
git remote set-url origin https://github.com/NanQING02/2026.3.15cleaningcar-codex.git
git branch
```

执行后你会得到一个可继续提交、建分支、查看历史的 Git 仓库。

## 如果需要继续推送

首次推送可使用：

```bash
git push -u origin codex/rk3588-dev-min
```

后续继续在板端新建功能分支即可，例如：

```bash
git switch -c codex/rk3588-next
```
