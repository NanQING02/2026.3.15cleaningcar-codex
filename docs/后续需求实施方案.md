## 1. 已完成并落地

### 1.1 外部程序运行检测 / 死机自启

落点文件：

- `cleaningcar/runtime_config.py`
- `cleaningcar/runtime_signals.py`
- `cleaningcar/pipeline.py`
- `web/inference.py`

结果：

- 推理进程持续写心跳
- guardian 检查心跳与进度
- 真卡死时自动终止并重启

### 1.2 明显启动信号

落点文件：

- `config_manager.py`
- `cleaningcar/runtime_signals.py`
- `cleaningcar/pipeline.py`

结果：

- 首次成功处理后写入 `[startup-signal]`
- 生成启动标志文件
- 自动保存启动截图

### 1.3 保留截图命令与功能

落点文件：

- `cleaningcar/runtime_signals.py`
- `cleaningcar/pipeline.py`
- `web/models.py`
- `web/server.py`

结果：

- 支持命令目录投递 `keep_snapshot`
- 支持 Web `POST /snapshot/keep`
- 可同时保留原图和标注图

### 1.4 事件截图修复

落点文件：

- `cleaningcar/events.py`

结果：

- 补齐了事件截图缺失的 `cv2` 导入
- 截图只有真实落盘成功后才写 `captureImage`
- 失败日志包含事件类型、轨迹 ID、路径、帧状态、`imwrite` 返回值和异常

### 1.5 车牌字符表与锁定链路修复

落点文件：

- `cleaningcar/constants.py`
- `cleaningcar/plate_lpr.py`
- `cleaningcar/plate.py`

结果：

- 以 `test_lpr_full.py` 的字符表作为唯一基准
- 统一了项目内车牌字符定义来源
- 同步修正了规范化、合法性校验与锁定口径

### 1.6 中文显示修复

落点文件：

- `cleaningcar/text_render.py`
- `cleaningcar/worker.py`
- `cleaningcar/pipeline.py`
- `fonts/platech.ttf`
- `requirements.txt`

结果：

- 车型中文、车牌省份汉字、车牌颜色文本已支持正常显示
- 主字体固定为 `fonts/platech.ttf`
- 无项目字体时按固定系统字体顺序兜底
