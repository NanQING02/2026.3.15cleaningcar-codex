# 项目功能与使用说明

## 1. 当前项目具备的功能

### 1.1 主检测链路

- 使用 `models/detection/best.rknn` 做车辆、清洗相关目标检测
- 按 `configs/*.json` 中的 ROI、流向和业务规则做事件判定
- 输出事件 JSON、事件截图、检测 CSV 和调试画面

### 1.2 车牌识别链路

- 当前只启用双模型车牌链路
- 车牌检测模型：`models/plate/plate_detect.rknn`
- 车牌识别/颜色模型：`models/plate/plate_rec_color.rknn`
- 运行代码位于：
  - `cleaningcar/plate_lpr.py`
  - `cleaningcar/worker.py`
  - `cleaningcar/plate.py`

### 1.3 车牌字符表修复

- 项目现以 `test_lpr_full.py` 的字符表为唯一基准
- 已统一到 `cleaningcar/constants.py` 和 `cleaningcar/plate_lpr.py`
- `cleaningcar/plate.py` 的规范化、合法性校验和锁定链路已同步

### 1.4 中文显示修复

- 新增 `cleaningcar/text_render.py` 统一渲染中文
- 车型中文标签不再显示 `??`
- 车牌中的省份汉字、颜色文字不再显示 `??`
- 主字体固定为 `fonts/platech.ttf`

### 1.5 事件截图链路

- 事件截图由 `cleaningcar/events.py` 保存
- 只有在截图文件真实存在时，事件 JSON 才写入 `captureImage`
- 截图失败会输出明确日志，便于板端排查

### 1.6 Web 管理能力

- Web 首页提供 ROI 与配置管理
- 支持推理启动、停止、重启
- 支持查看推理状态、健康状态和日志
- 支持手动保留截图

### 1.7 运行保障能力

- guardian 负责守护推理进程
- 基于心跳和进度判断真卡死
- 异常时自动拉起推理进程

### 1.8 启动信号与截图

- 启动成功后写日志 `[startup-signal]`
- 生成启动标志文件
- 自动保存启动截图到 `captures/startup/`
- 手动截图保存到 `captures/manual/`

### 1.9 单车视频输出

- 单车视频目录由 `logic.per_id_video_dir` 控制
- 默认输出到 `video_result/per_id/`
- 路径留空或不可写时会自动回退本地目录

## 2. 当前目录结构

- `cleaningcar/`
  - 主运行包
- `web/`
  - FastAPI 管理层与 guardian
- `configs/`
  - 运行配置
- `models/`
  - 当前使用的 RKNN 模型
- `fonts/`
  - 项目内置字体目录，当前使用 `platech.ttf`
- `future_modules/`
  - 预留但当前未启用模块
- `packages/`
  - RKNN / RGA 运行依赖
- `docs/`
  - 项目说明、实施方案、验收说明

## 3. 启动方式

### 3.1 脚本启动

```bash
chmod +x install_runtime_venv.sh
./install_runtime_venv.sh
```

### 3.2 手动启动 Web

```bash
source venv-gst/bin/activate
python -m web.server --config configs/config.json --host 0.0.0.0 --port 8000
```

### 3.3 直接启动主程序

```bash
source venv-gst/bin/activate
python run_zone_detect.py --config configs/config.json
```

### 3.4 切换 FP 后处理模式

```bash
python run_zone_detect.py --config configs/config.json --fp_output_mode 6
python run_zone_detect.py --config configs/config.json --fp_output_mode 9
```

## 4. 关键输出位置

- 事件 JSON：`events/<配置名>/`
- 事件截图：`captures/<配置名>/`
- 启动截图：`captures/startup/`
- 手动截图：`captures/manual/`
- 单车视频：`video_result/per_id/`
- 推理日志：`logs/inference/`
- Web 启动日志：`web_server_8000.log`

## 5. 板端部署提醒

- 部署时必须带上 `fonts/platech.ttf`
- `requirements.txt` 已包含 `Pillow`
- 验收时应同时检查：
  - `/inference/health` 保持 `ok`
  - `restart_count` 不增长
  - 心跳持续更新
  - 事件 JSON 正常生成
  - `captureImage` 非空且文件真实存在
  - 中文标签显示正常
