# docs 文档索引

`docs/` 里的文档现在分成两层：

- 当前总览与当前部署口径
  - 这些文档默认面向“现在这份仓库”
  - 适合第一次接手项目或给其他 agent 建立上下文
- 条件性 / 专项 / 带时间基准的文档
  - 这些文档通常绑定某次甲方环境、某轮性能评估或某个专项问题
  - 不能直接当成当前代码和默认配置的唯一事实来源

建立上下文时，建议先看仓库根 `README.md`，再回到本目录。
