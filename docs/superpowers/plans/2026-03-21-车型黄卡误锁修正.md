# 车型黄卡误锁修正 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有车型锁定流程中加入“非黄色车型覆盖黄色卡车误锁”的规则，减少黄色卡车样本偏置导致的误锁。

**Architecture:** 保留现有 `class_counts + confirmed freeze` 的主流程，只在当前锁定候选为 `yellow truck` 时增加一条专门的覆盖分支。覆盖分支依据最近窗口内的非黄色车型稳定出现时长，或连续高置信观测，直接把锁定结果切到该非黄色车型并冻结，避免后续再被黄色卡车抢回。

**Tech Stack:** Python, pytest
