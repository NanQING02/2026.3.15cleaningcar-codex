## 2. 当前建议的板端复测项

1. 执行 `./install_runtime_venv.sh`，确认环境安装完成后不会自动拉起 Web
2. 以 `source venv-gst/bin/activate && ./start_web_server.sh start` 启 Web，确认 8000 端口监听正常
3. 启动推理，确认 `/inference/health` 持续为 `ok`
4. 观察 `restart_count` 不增长
5. 检查事件 JSON 正常生成
6. 检查 `captureImage` 非空且文件真实存在
7. 检查 `captures/startup/` 与 `captures/manual/` 继续正常
8. 检查车型中文和车牌汉字不再显示 `??`
9. 检查 `video_result/per_id/` 与截图清理策略按配置生效
