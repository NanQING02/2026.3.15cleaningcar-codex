# 规划记录目录

本目录用于收口“已经完成的开发记录”和“后续待开发事项”。当前主入口已经改成双分区结构，先看主文档，再按需要进入历史记录。

## 阅读顺序

1. 先看 `已完成开发与使用说明.md`
2. 再看 `待开发事项总表.md`
3. 需要追溯实施细节时，再进入历史与补充文档

## 已完成开发

- `已完成开发与使用说明.md`
  - 当前已经落地的功能总入口
  - 重点说明“现在有什么、怎么用、配置在哪里、板端怎么验收”

## 待开发事项

- `待开发事项总表.md`
  - 当前后续开发主入口
  - 覆盖 `PLAN.md` 未完成事项和事件触发机制修改占位卡
- `性能优化优先级与路线图.md`
  - 性能专项的主文档
  - 按“最方便先做”和“性价比/优化力度”两条线整理优先级
- `RGA启用与兼容性评估计划.md`
  - RGA 缩放接入前的专项评估文档
  - 重点记录当前仓库现状、甲方板端兼容风险和建议开工顺序

## 历史与补充文档

- `后续需求实施方案.md`
  - 历史实施快照
  - 适合回看本轮改动的阶段性落地记录和当时的复测建议
- `后置项记录.md`
  - 历史临时清单
  - 其中剩余有效内容已并入 `待开发事项总表.md`
- `清理与服务化双分支计划.md`
  - 清理策略与服务化改造的专项落地记录

## 说明

- 本 `README.md` 只负责索引，不重复展开实现细节
- 对“当前状态”的正式口径，以 `已完成开发与使用说明.md` 和 `待开发事项总表.md` 为准
