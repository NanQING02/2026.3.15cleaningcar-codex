# 运行路径说明

项目运行时会读写以下路径。

## 配置文件

- 默认主配置：`configs/config.json`
- 备用配置：`configs/config_绕行.json`

## 模型路径

- 检测模型：`models/detection/best.rknn`
- 车牌检测：`models/plate/plate_detect.rknn`
- 车牌识别：`models/plate/plate_rec_color.rknn`

## 检测后处理切换

由配置项控制：

- `video.fp_output_mode=6`
  - 默认模式
  - 9 输出模型也只用 `box + class`
- `video.fp_output_mode=9`
  - 使用 `box + class + score`

## 主程序输出目录

### 事件输出

由 `event_output_dir` 控制，例如：

- `events/config`
- `events/config_绕行`

目录内通常包含：

- 事件 JSON
- `event_log.csv`
- 上传队列数据库

### 截图输出

由 `event_capture_dir` 控制，例如：

- `captures/config`
- `captures/config_绕行`

### 启动截图

由 `system.startup_capture_dir` 控制，默认：

- `captures/startup`

说明：

- 这是自动启动截图目录
- 当主流程首次真正产出结果后，会自动保存启动截图到这里

### 手动截图

由 `system.manual_capture_dir` 控制，默认：

- `captures/manual`

### 调试帧

由 `video.debug_frame_path` 控制，例如：

- `/dev/shm/cleaningcar_debug_A.jpg`
- `/dev/shm/cleaningcar_debug_B.jpg`

### 单车视频

由 `logic.per_id_video_dir` 控制，默认：

- `video_result/per_id`

说明：

- 配置为空或只填空白时，等价于默认本地目录
- 如果配置路径不可写，运行时会自动回退到 `video_result/per_id`

## 运行控制文件

### 心跳文件

由 `system.heartbeat_path` 控制，默认：

- `/dev/shm/cleaningcar_heartbeat.json`

### 启动标志

由 `system.startup_flag_path` 控制，默认：

- `/dev/shm/cleaningcar_started.flag`

### 命令目录

由 `system.command_dir` 控制，默认：

- `/dev/shm/cleaningcar_cmd`

支持放入：

- `*.cmd.json`
  - 例如 `keep_snapshot` 命令

## Web 相关

- Web 启动日志：`web_server_8000.log`
- 推理日志目录：`logs/inference/`
- Web 入口：`http://<设备IP>:8000/`
