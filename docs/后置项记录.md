# 后置项记录

## 1. 截图清理策略

当前项目已经保证“该生成的截图必须成功落盘”，但还没有实现自动清理。后续建议统一做一套清理策略，覆盖以下目录：

- `captures/<配置名>/`
- `captures/startup/`
- `captures/manual/`

建议方式：

- 按保留数量清理
- 按天数清理
- 清理前保留最近一次启动截图和最近一次手动截图

## 2. 服务化整理

- 评估是否需要将 `install_runtime_venv.sh` / `stop_runtime_venv.sh` 进一步收口为 `systemd` 模板
- 若后续完全转为系统服务管理，可再决定是否保留当前脚本

## 3. 配置进一步清单化

- 将高频配置项单独整理为板端交付清单
- 补一份“最小可运行配置”和“一键验收配置”样板

## 4. 非本轮范围

以下内容本轮不做，避免继续扩大改动面：

- 额外 HTTP 接口扩展
- 模型结构调整
- 车牌前后处理算法重写
